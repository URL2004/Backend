# 감사 후 1차 품질 보완

엔진 `gpt-prod-v2.5.104`, 전처리 버전 37. 범위는 전처리·구조 보호, 최종 후보 추적, 코칭·추천 정합성이다. 이력 일치 조건, 점수 보정, 하한·상한, 표시 점수와 전후 비교 정책은 변경하지 않는다.

## 동작

- 셀 구분자가 사라진 평문 표에서 영역·위험요인·개선 과제 헤더와 반복 행을 함께 인식한다. 헤더가 모두 확인된 부분 복사 표도 줄 경계를 보존한다. 열이나 누락 내용을 만들어 넣지 않는다. 같은 인식이 전처리·청크 잠금·관계 digest에 적용돼 셀 병합에 공백 동등 검증을 재사용하지 않는다.
- 긴 미완결 산문의 종결·연결 어미 조각을 문맥으로 구별한다. 인접한 같은 단계의 가나다 목록 증거가 우선하며, 목록이 가부터 시작할 필요는 없다. 짧은 시·명시적 구조·코드는 보호한다.
- 원문 정규화 전후 digest와 변경 구간, 선택 후보 digest·단계·사유·복귀 여부, 최종 검증 대상 digest·상태·허용 변환 종류를 이력과 작업 보관 문서에 저장한다. 후보 원장과 본문은 추가 복제하지 않는다. 필드가 없는 과거 기록은 미확인 상태로 남는다.
- 보고서 제목·등급·문단 안내·코칭은 내용 근거의 축 정책을 공유한다. `off`, `sparse`, `limited`를 결핍으로 바꾸지 않는다. 기존 내부 모드 라우팅과 요금 계산에는 같은 입력을 계속 사용한다.
- 위치가 맞아도 어미·조사만 남은 조각은 문체 재작성 후보에서 제외하고 입력 확인 안내로 분리한다. 실제 문장은 legacy 대상 수와 무관하게 유지한다. 문자열 길이와 위치는 UTF-16 기준이며, 짧은 정상 답변은 일괄 제외하지 않는다.

## 추가 메타데이터

| 필드 | 내용 |
|---|---|
| `sourceNormalization` | 제출·정규화·무결성 기준 원문의 SHA256, 변경 여부, 변경 전체를 포함하는 UTF-16 구간 |
| `candidateLedgerSelectedDigest` 및 `candidateLedger*` 요약 | 선택 단계·사유·복귀 여부·개수. 선택 이후 허용 편집이 있을 수 있어 반환 해시와 무조건 같은 값으로 간주하지 않는다 |
| `finalValidationReceipt` | 실제 반환 해시, 검증 대상 해시, `exact`/`whitespace_layout`, 최종 확인 상태와 부모 검증 해시 |
| `reportView.conversion.candidatePolicyVersion` | `candidate-editability-v1` |
| `reportView.conversion.inputReview` | 조각 확인 안내와 제한된 위치 목록. 점수 변경 근거가 아님 |
| `contentAssessmentStatus` | 내용 근거 평가 상태. 미평가일 때 `grade`와 공개 `abstractRiskRatio`는 null |

`sourceNormalization.changeRange`는 여러 편집을 포함하는 외곽 구간이다. 편집마다 일대일 위치가 복원됐다는 뜻이 아니다. 구조 판단과 어미 판단은 제한적인 결정론 규칙이며 새로운 전체 의미 검증을 대신하지 않는다.

## 검수

합성 fixture로 표·부분 목록·시·코드·공백 동등 관계, 원장 저장 및 보관 왕복, 정상 후보와 입력 조각, 코칭 평가 상태를 검사한다. 고정된 서명 이력과 설정에서 62→37, 18→11, 10→10 및 비교 정책을 회귀시험한다. API 시험은 로컬 provider·과금 대역을 사용한다.

사용자 자료의 로컬 재검증 결과와 실행 로그는 저장소 밖 보고서 폴더에 보관한다. 검증되지 않은 변경을 배포하거나 이 문서를 배포 완료 근거로 사용하지 않는다. 사실 강도·화자·시적 표현의 보존 보강과 호출 최적화는 다음 묶음이다.
