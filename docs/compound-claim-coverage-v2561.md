# v2.5.61 — 복합 문장 내부 비교 결과 누락 보강

작성: 2026-09-20. 기준 커밋: `82ef0656` (v2.5.60).

## 확인한 결함과 범위

문장 앞쪽의 비교 결과가 남아 있어도 뒤쪽의 독립된 비교 결과가 빠질 수 있다.
기존 누락 복원기는 이 경우 원문 문장 전체를 삽입하여 이미 남아 있는 앞 절을
중복시킬 수 있었다. 첨부 사례를 로컬 재현하여 확인했다. 문단 분리 또는
dedupe 단독 실행에서는 해당 삭제가 재현되지 않았다.

운영 작업의 생성·수리 단계별 원인은 아직 확정하지 않았다. 운영 조회 인증이
401을 반환하여 해당 작업의 실제 실행 경로를 확인하지 못했다.

## 구현

- 복합 문장의 앞 절과 뒤 절을 따로 대조하는 제한된 누락 후보 검사를 추가했다.
  후보는 오류 확정이나 사용자 경고가 아니며 기존 의미 심사의 검토 자료이다.
- 후보가 있으면 기본 모드의 짧은 입력도 의미 심사를 생략하지 않는다.
- 의미 심사기가 원문 근거를 확인한 수리 가능한 누락만 절 단위 복원을 허용한다.
  남아 있는 편집 문장을 그대로 두고 빠진 뒤 절만 원문에서 가져온다.
- 복원했다는 이유로 원래 누락 판정을 제거하지 않는다. 기존 후보 무결성 검사와
  최종 의미 재검증을 거쳐야 한다.
- 이미 별도 문장·문단으로 남은 내용, 직접 인용·코드, 애매한 반복 대응을 제외한다.
- 대조 관계 또는 일부만 남은 여러 주장에는 결정론적 삽입을 하지 않는다.
  기존 모델 수리 경로에 맡기며 원문 문장 통째 삽입으로 중복시키지 않는다.
- 신규 관측 필드는 후보 수와 채택 복원 수뿐이다. 원문·인용·프롬프트를 저장하지 않는다.

생성 프롬프트의 보존 지시는 추가하지 않았다. 의미 심사 지시만 보강하며 기존
생성 프롬프트 길이 제한을 유지한다. 모델·요금·차단·무차감 정책과 감지 버전은
변경하지 않는다. 후보 검사는 별도의 모델 호출을 만들지 않지만, 이전에 생략되던
기존 의미 심사가 실행될 수 있으므로 해당 요청의 시간·비용은 달라질 수 있다.

## 검증

- 전체 자동 테스트: **1,826/1,826 통과**, 실패·스킵 0.
- 신규 단위 테스트 9건: 절 누락, 중복 없는 복원, 불확실·미확인 판정,
  분리 문장·문단, 인용·코드, 대조 관계, 반복 대응, 의역, 부분 잔존.
- 신규 엔진 통합 테스트 1건: 모델 수리가 실패해도 확인된 뒤 절만 한 번 복원하고,
  앞 절 편집을 유지하며 최종 의미 심사가 다시 실행되는지 mock으로 검증.
- 기존 원문–결과 415쌍에 로컬 후보 검사: 후보 문서 2건, 후보 2개.
  모듈 실행 시간 p95 약 3.5ms, 최대 약 18.9ms. 운영 지연 지표가 아니다.
- 첨부 사례: 후보 1개, 명시적인 누락 확인을 모사했을 때 뒤 절 1개 복원,
  기존 누락 판정은 재검증 전 유지, 같은 복원을 다시 수행했을 때 추가 삽입 0개.

원문·결과·개인 식별자는 저장소 밖 로컬 자료로만 취급했고, 커밋한 테스트는
합성 예문을 사용했다. 415쌍 전체의 수동 의미 검수나 실제 모델 재실행은 하지
않았으므로 위 수치를 전체 누락 탐지 정확도 또는 운영 성과로 해석하면 안 된다.

## 남은 제한과 운영 확인

이번 후보 검사는 일정한 한국어 연결어와 독립 술어가 있는 뒤 절 누락에 한정된다.
앞 절만 빠지거나 대폭 의역되어 대응이 불확실한 경우까지 완전 탐지한다고
주장하지 않는다. 기존 문서 의미 심사가 계속 필요하다.

운영 반영 전 실제 모델로 누락 확인·수리·재검증을 확인하고, 반영 후 신규 후보 수,
복원 수, 잔여 의미 경고와 심사 시간·비용을 확인해야 한다. 실제 모델 검사 및
운영 배포는 이번 로컬 검증에 포함되지 않았다.
