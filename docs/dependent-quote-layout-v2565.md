# v2.5.65 문장 종속 인용의 문단 소유권 수정

2026-09-24 · 후속 검증 완료, 운영 미배포

## 근본 원인

1. 기존 인용 줄바꿈 수리는 원문에 없던 새 오류를 주로 복원했다. 원문부터 나뉜 문장 외곽 공백은 그대로 남았다.
2. 문장 일부인 인용이 독립 제목·인용 블록으로 분류되어 청크와 복원 단계에서 잠겼다. 앞의 불완전한 도입절도 제목으로 오인했다.
3. 잘게 나뉜 짧은 행이 창작문 판정과 exact-line 정책을 유발했다. 겉으로는 정상 보호였지만 원인이 잘못된 장르 신호였다.
4. 원문 공백을 정규화한 뒤에도 이전 문체 프로필의 문단 수가 남아 정상 통합을 구조 변경으로 경고했다.

## 변경

- 공통 `dependentQuoteLayout`이 인용과 조사·서술격 어미, 앞의 불완전한 절의 연결을 판정한다. 인용 내부 문자는 그대로 두고 바깥 공백만 바꾼다.
- 문장에 종속된 인용을 구조 판정·청크 소유권·입력 정규화·최종 형식 보정에서 일관되게 취급한다.
- 원문이 이미 잘못 분절되어 있어도 본문에 연결된 인용은 정리한다. 독립 인용·완결 문장·표·탭·코드·참고문헌·명시적 제목은 유지한다.
- 창작문 판단의 짧은 행 통계에서 종속 인용의 가짜 조각을 제외한다. 명시적인 창작·행 보존 정책은 유지한다.
- 정규화 후 문체 프로필을 재계산한다. `sourceDependentQuoteRepairCount`는 내용 없는 횟수만 남긴다.
- 장르 판단 변경을 감지 캐시와 구분하기 위해 감지 버전을 v1.40으로 갱신했다. 점수 하향 보정은 추가하지 않았다.
- 실제 재생성에서 발견한 신규 한자 한 글자 혼입은 유일한 원문 한글 어절과 뒤 서술어 문맥이 확인될 때만 복원한다. 원문에 한자가 있거나 대응이 모호하면 추정하지 않는다. 일본어·중국어와 인용·코드를 차단하거나 일괄 치환하지 않는다.
- 모델, 가격, 전달·과금 정책, 동시성, 묶음 호출 플래그는 유지한다.

## 검증

- 전체 자동 회귀 1,935개 통과. 직접 인용 내용 변경·독립 제목 병합은 여전히 실패한다.
- 인용부호 8종, 중첩 인용, 조사/서술격 어미, CRLF, 공백, 정상 독립 문단, 코드, 참고문헌, 표, 모호한 원문 대응을 검사했다.
- 기본·고급 전체 엔진에서 결과의 문장 연결, 구조 통과, 잘못된 문단 경고 부재를 확인했다. 고급 의미 검증도 통과한다.
- 기존 986건(휴머나이징 579쌍·감지 407건) 재생에서 추가 결과·장르 변경 및 구조 판정 변화는 없었다. 새 재현을 별도 회귀로 추가했다.
- 5,050자 실제 장문 재생성: 140.542초, 의미·구조·인용 통과, 품질 경고 0건, 실질 편집률 16.7%. 원문과 결과 전체를 직접 대조했다. 표·수치·날짜·직접 인용·서술자의 경험이 유지됐다. 외부 사실의 진위 확인은 별개다.
- 첨부 620자 구간의 실제 고급 재실행: 87.982초/11회 호출에서 15.415초/2회 호출. 인용 주변 경계 4곳을 정리했고 실질 편집률은 26.21%. 실제 출력에 발견된 한 글자 혼입까지 원문 근거로 교정한 뒤 별도 의미 재심사를 통과했다. 마지막 표기 교정은 전체 신규 생성이 아닌 수정 후보 재심사다.
- 누적 실호출 상한 추정 $1.86288661, 보수적 환율 2,000원과 20% 여유 포함 약 4,471원. 동일 5,000원 예산이며 사용자 크레딧은 차감하지 않았다.

## 성능 해석과 제한

20문단·120문장 로컬 반복 측정의 정렬 p95는 두 실행에서 40.9ms와 63.0ms, 새 인용 수리는 0.34ms와 0.55ms였다. 동시 작업 3개 결과와 취소 전파를 확인했다. 이벤트 루프 최대 지연은 51.8ms와 92.3ms로 50ms 목표를 일관되게 달성하지 못했다. 이 측정과 두 실문서 결과를 전체 운영 p95나 모든 장르 품질의 보장으로 해석하지 않는다.

생성 글의 모든 문체 선택이 최적임을 보장하는 패치는 아니다. 장문 실출력에는 의미 손상이 아닌 표현 중복도 일부 남았다. 이번 수정의 합격 범위는 재현된 문장 분절·잘못된 보호·감사 기준 불일치·신규 문자 혼입이다. 운영 배포 완료를 뜻하지 않는다.
