# AI 감지 반복 점수 개선 구현·검증 기록

작성: 2026-09-14 KST. 기준: 운영 `b0b8efd`, 감지 `gpt-detect-v1.32`.

## 결론

개선 후보 구현 및 소규모 실제 API 비교는 완료했지만 **두 후보 모두 운영 활성화 불가**다.
일부 문제 글에서 편차가 줄어든 것만으로 전체 품질이 개선됐다고 판단하지 않는다.
현재 운영 점수, 감지 모델, 과금, 원문 이력 보정, 캐시 TTL은 변경하지 않았다.
모델의 문체 점수는 실제 AI 작성 확률이나 작성 주체의 증명이 아니다.

## 구현

- `DETECT_CONSISTENCY_ENABLED=1`: 근거 충분성(confidence)과 별개로 경계 점수·추상/상투 신호 혼합을 재검사한다. 기본 OFF.
- `DETECT_EVIDENCE_CRITERIA_ENABLED=1`: 장르 관습/반대 근거, 강도와 범위의 구분, 중복 원인 방지 및 의미 보존 편집의 대조 예시를 포함한 별도 프롬프트. 기본 OFF.
- 두 플래그는 독립적이다. 동일 가중치 점수 합산 후보를 운영에 재사용하지 않는다.
- 재검사에는 이전 점수·판정을 보내지 않는다. 보안용 무작위 입력 경계도 유지한다.
- 첫 두 판정의 점수 구간·원인·강도가 일치하고 차이가 6점 이하면 종료한다. 불일치 시 최대 한 번 추가로 읽는다.
- 3개 판정에서는 서버 근거 상한 적용 후 중앙값에 해당하는 **실제 점수·근거 쌍**을 선택한다. 평균 점수와 임의의 설명을 조합하지 않는다. 무조건 낮은 값을 선택하지 않는다.
- 최대 3회는 논리적 모델 호출 수다. HTTP transport 재시도는 기존 정책 및 공통 절대 시간 제한을 따른다. 추가 호출 전 잔여 10초 미만이면 시작하지 않는다.
- 재검사 실패·시간 부족 시 유효한 최초 결과를 유지한다. 사용자 취소는 즉시 전파하며 사용자 차단·재과금은 추가하지 않는다.
- 선택되지 않은 성공 호출 및 실패 응답의 알려진 사용량도 합산한다. 실패 시 공급자 과금이 미확인일 수 있음을 숫자/불리언 진단으로 남긴다.
- 마지막 호출이 아닌 실제 선택 호출의 `selectedPhase`를 기록한다. 점수 차이, 합의 여부, 호출 수·실패 수는 원문 없이 기록한다. 결과 캐시의 삭제 보호·원문 지문·사용자 분리 유지.
- 두 플래그를 캐시 버전에 포함해 실험/기존 결과가 섞이지 않게 한다.
- predeploy는 두 연구 플래그가 켜진 운영 환경을 불합격 처리한다. 실제 서비스 차단 정책이 아니라 배포 설정 검사다.

## 실호출 방법

고유 입력 6개: 기존 운영 문제 글 2개(작성 주체 미확정), 과거 학습/개발 데이터의 설명문 인간 참고/AI 각 1개, 짧은 후기 인간 참고/AI 각 1개.
기존 보류 holdout은 다시 열지 않았다. 참고 인간 라벨은 데이터 출처 기준이며 개별 글의 확정적인 작성 주체 증명은 아니다.
각 실험에서 기존/후보를 번갈아 3회씩 호출: 36회 감지 실행. 두 실험 합계 **72회 실행, 94회 모델 호출**.
결과 캐시와 휴머나이징 이력 보정을 제외한 엔진 직접 호출이다. 사용자 크레딧/운영 문서 쓰기는 없다.
실험 1과 2는 각각 동시기에 다시 측정한 기준선과 비교한다. 서로 다른 실행의 기준선을 선택적으로 섞지 않는다.
API 사용량 기반 총 추정 비용 **$0.044359**. 공급자 최종 청구액은 아니다. 로컬 테스트 한도 $0.15 내 완료.

### 실험 1: 기준 문구 변경 + 선택적 재검사

| 입력 | 기존 반복 범위 | 후보 반복 범위 | 기존 중앙값 | 후보 중앙값 |
|---|---:|---:|---:|---:|
| 문제 글 A | 17 | 0 | 38 | 34 |
| 문제 글 B | 1 | 6 | 42 | 34 |
| 인간 참고 설명문 | 11 | 10 | 12 | 8 |
| AI 설명문 | 7 | 8 | 34 | 16 |
| 인간 참고 짧은 후기 | 6 | 0 | 3 | 3 |
| AI 짧은 후기 | 7 | 5 | 12 | 8 |

문제 글 A는 38/38/55 → 34/34/34. 그러나 AI 설명문이 21점 이상 구간에서 낮은 구간으로 이동했고, 모든 글에서 편차가 개선된 것도 아니다.
기존/후보 각각 18회 실행의 추정 비용 $0.007918/$0.011260 (**약 +42.2%**), 표본 p95 5.362/11.127초 (**약 +107.5%**).
선택적 재검사 18회 중 4회, 후보 모델 호출 총 23회. **불합격**.

### 실험 2: 기존 문구 + 선택적 재검사

| 입력 | 기존 반복 범위 | 후보 반복 범위 | 기존 중앙값 | 후보 중앙값 |
|---|---:|---:|---:|---:|
| 문제 글 A | 5 | 14 | 38 | 54 |
| 문제 글 B | 18 | 16 | 42 | 58 |
| 인간 참고 설명문 | 15 | 14 | 16 | 8 |
| AI 설명문 | 10 | 14 | 29 | 36 |
| 인간 참고 짧은 후기 | 0 | 6 | 3 | 8 |
| AI 짧은 후기 | 4 | 6 | 8 | 16 |

재검사만으로 편차가 일관되게 줄지 않았다. 점수가 내려가는 방향으로만 작동한 것도 아니다.
기존/후보 추정 비용 $0.007897/$0.017284 (**약 +118.9%**), 표본 p95 6.108/14.518초 (**약 +137.7%**).
후보 모델 호출 총 35회. **불합격**.

두 실험 모두 인간 참고 2개와 AI 2개만 있으므로 오탐률/탐지율의 일반적인 개선을 주장할 수 없다. 50점 기준에서는 두 실험의 기존/후보 모두 이 AI 2개를 탐지하지 못했다.
출력 72건은 독립적인 글 72개가 아니다. p95 역시 소표본 관찰치이며 운영 p95 추정이 아니다.

## 자동 검증 및 안전 경계

전체 자동 테스트 **1,572/1,572 통과**, 실패·스킵 0. 신규 16개 테스트 포함. production import graph 및 `git diff --check` 통과.
자동 테스트는 구현 계약과 회귀를 확인하는 것이며, 위 실호출 품질/성능 불합격을 대신하지 않는다.

새 회귀 테스트는 동작 OFF/ON 분리, 같은 모델 재검사, 호출 상한, 실패·취소·시간 제한, 선택 결과의 점수/근거/단계 일치, 전체 사용량 합산, 캐시 분리, 진단 개인정보 제거를 검사한다.
`evaluateConsistencyComparison`은 캐시 없는 동시기 쌍별 반복만 받아들이며, 불충분한 반복·비용 누락·작성 주체 라벨 누락·중복 입력을 거부한다.
점수 하향 평준화, 인간 오탐 증가, AI 감지 민감도 하락, 비용·시간 증가를 통과로 처리하지 않는다. 메트릭만으로 releaseEligible을 true로 만들지 않는다.
단문은 반복 호출로 부족한 근거를 만들어내지 않는다. 의미가 달라진 글의 점수를 억지로 동일하게 만들지 않는다.

## 다음 실험의 조건

1. 두 후보는 기본 OFF로 유지한다. 문구 변경/추가 검사/최종 선택 각각의 기여도를 분리한다.
2. 이번에 노출된 6개는 개발 자료로만 사용한다. 장르별 원인 강도와 반대 근거를 사람이 평가한 별도 자료를 확보한다.
3. 자유 점수의 분산과 신호 강도 판정의 분산을 따로 측정한다. 검증되지 않은 숫자 환산식을 운영에 도입하지 않는다.
4. 목표는 반복 최대 차이 6점 이하, 의미 보존 최소 편집 중앙값 차이 5점 이하, 오탐 증가 없음, 비용·p95 증가 30% 이내다. 실제 의미가 바뀐 대조군도 포함한다.
5. 목표 달성 후에도 최소 5개 장르의 인간/AI 검증 표본과 미사용 holdout, 수동 검토를 거쳐 운영 활성화를 별도 판단한다.

근거 기준과 사람이 평가한 정답의 비교를 분리하는 방식은 [OpenAI 공식 평가 지침](https://developers.openai.com/api/docs/guides/evaluation-best-practices#llm-as-a-judge-and-model-graders)을 참고했다. 이것은 현재 후보의 정확성이나 점수 안정성을 보장하지 않는다.
