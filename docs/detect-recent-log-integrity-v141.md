## 재현한 근본 결함과 수정

### 1. 모델 문장 번호와 화면 문장 번호의 혼용

모델은 인용·코드 보호 후 원문 span에 번호를 매긴다. 화면은 별도의 보고서 분할기로
단일 줄바꿈·제목·긴 한 문단을 나눈 뒤 번호를 매긴다. 같은 정수라도 다른 문장을
가리킬 수 있는데, 프런트의 원인 클릭은 그 번호를 문장 지도 ID로 사용했다.
문단도 모델에서는 빈 줄 기준인 반면 화면에서는 단일 줄바꿈까지 나뉘었다.

- 최근: 위치 근거가 있는 10건 중 7건, 89개 위치 중 44개가 화면 ID/문단/범위와 불일치.
- 과거: 위치 근거가 있는 377건 중 157건, 5,025개 위치 중 2,056개 불일치.
- 단순 번호 차이도 포함하는 수치이며 모두 다른 문장을 실제로 클릭했다는 접속 추적 수치는 아니다.

수정은 점수 모델의 입력이나 원인 ID를 바꾸는 대신 공개 보고서 경계에서 수행한다.
보고서 분할 전 원문의 정확한 문자 위치를 보존하고, 검증된 모델 범위를 화면 문장에
투영한다. 공백 정규화만 허용하며 비공백 문자가 달라지면 위치를 추측하지 않는다.
반복 문장은 앞에서부터 단조 대응하고, 긴 문서의 발췌 상한 밖에도 텍스트 없는 좌표를 유지한다.
지도 생성 실패 시에도 다른 문장에 근거를 붙이는 fallback을 하지 않는다.

### 2. 부분 설명과 완전 정렬의 동시 표시

최근 3건은 모델 점수 16/9/18에서 기존 통계 정책으로 표시 점수 49가 됐다.
문장별 설명은 `partial`인데 보고서 전체는 `ready/aligned`였다.
숫자를 지지하는 통계가 있다는 것과 원문 문장으로 점수를 충분히 설명할 수 있다는
것을 같은 상태로 취급한 것이 원인이다. 과거 407건에서도 동일 상태 모순 3건을 확인했다.

- 점수 지지 상태는 유지하되 문장별 `explanationStatus`를 구분한다.
- 통계가 반영됐거나 위치 설명이 부족하면 보고서 정렬/종합 설명도 부분 설명으로 통일한다.
- 낮은 신뢰도·불충분한 표본의 제한 설명은 종합 설명에서도 동일하게 사용한다.
- 보정 전 통계 지원 정보가 현재 표시 점수와 다르면 현재 점수의 근거로 재사용하지 않는다.
- 점수·요금·모델·임계값·이력 보정·전달/과금 정책은 변경하지 않는다.
