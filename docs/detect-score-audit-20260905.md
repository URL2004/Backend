# 감지 점수 결측치와 근거 보존 보완

## 문제와 결과

원문 감지 점수가 없는 휴머나이징 작업의 `null`이 `Number(null)`에서 0으로 바뀌어 이력에 저장됐다. 이 값을 재검사 상한으로 읽으면 정상 모델 점수도 0까지 내려갔다. 원점수를 브라우저에서 넘기는 기존 경로는 서버의 실제 측정값과 연결되지 않았고, 기존 휴머나이징 HMAC도 원점수를 서명하지 않았다.

`detectSourceScore`는 선택 점수의 결측치와 실제 0을 구분한다. 이력 저장 시 본인의 최근 이력 최대 50개에서 동일 원문에 대한 최신 서버 LLM 감지 결과를 확인하고, 일치하는 측정값만 출력·사용자에 결합해 별도로 서명한다. 이미 이력 보정을 거친 점수는 새 상한 근거로 재사용하지 않는다. 선택 점수가 없으면 추가 조회가 없다. 조회 실패나 일치 이력 부재는 결과 저장을 막지 않고 상한을 생략한다.

재검사는 별도 원점수 서명이 있는 값만 상한으로 사용한다. 구형 무서명 점수는 실제 0과 결측치의 오저장을 구분할 수 없어 상한에서 제외한다. 기존 작성 결과의 출처 검증과 비율 보정은 유지한다. 과거의 감지 결과나 크레딧 원장은 소급 수정하지 않는다.

## 감지 근거와 캐시

`model-signals-v2-grounded` 계약이 캐시의 구형 허용 목록에서 빠져 최초 응답을 정리할 때부터 계약 버전과 문장 위치가 없어졌다. 신규 캐시 정책은 버전과 제한된 숫자 좌표만 보존하며 인용문이나 임의 필드는 저장하지 않는다. 점수 결측치를 0점 결과로 캐시하지 않는다.

빈 신호 배열도 grounded v2 계약으로 인식한다. 낮은 점수에서 신호가 없더라도 모델 원점수는 보존하고, 근거 없는 높은 점수에는 기존 상한 규칙을 일관되게 적용한다. 모델이 숫자 점수를 반환하지 않은 경우 성공한 0점 결과로 처리하지 않는다.

감지 버전은 `gpt-detect-v1.26`, 안정화 캐시 버전은 `detect-result-stability-v3-grounded`, 이력 보정 버전은 `history-calibration-v3-source-verified`다. 휴머나이징 엔진 버전과 감지 모델·프롬프트·점수 구간은 유지한다. 캐시 버전 변경으로 이전에 근거가 누락된 결과를 새로운 정상 결과와 섞지 않는다.

## 검증과 해석

회귀 시험은 결측치/실제 0 구분, 사용자·입력·최신 이력 확인, 위조된 상한, 보정 점수의 재사용, 서명 변조, 기존 이력 필드 재저장, 최초 응답/메모리/Firestore 근거 좌표 보존을 다룬다. 기록해 둔 합성 모델 응답을 재생하여 정상 점수와 모델 호출 횟수가 동일함을 확인한다.

이 수정은 일반 감지 점수를 높이는 변경이 아니다. 현재 모델 점수는 관찰된 문체 신호의 척도이며 실제 AI 작성 확률로 검증된 값이 아니다. 비율 보정 역시 동일 본문에 대한 계정 이력에 따라 결과를 달리하므로 독립적인 탐지 정확도 평가에서는 반드시 분리해야 한다. 모델/프롬프트의 민감도를 바꾸려면 작성 출처가 확인된 한국어 사람 글과 AI 글의 장르·길이별 별도 평가가 필요하다.

사용자가 제외한 실행 중 취소·중단 동작은 변경하지 않는다.
