## 감지 점수 해석

53건의 선택 모델 평균은 약 25.0, 통계 후 27.0, 표시 26.5점이었다. 이력 일치 4건 중 기존 하한으로 점수가 그대로인 1건이 있다. 이 표본의 낮은 평균을 이력 보정이나 근거 상한 감산 탓으로 단정할 수 없다. 작성 경위는 전건 미확인이다.

승인된 설정 변경은 이력 하한 20→10뿐이다. 운영의 감산 비율 40%, 기본 최대 감산 30점, 검증된 원문 점수 상한 및 동일 사용자·서명·보수적 일치 조건은 유지한다. 25→15, 27→16, 34→20이며 원점수 0~9를 올리지 않는다. 0~100 전체 단조성·원점수 비상승을 검사한다.

유사 이력 일치의 어휘 변경 허용은 보수적으로 좁혔다. 긴 글의 3% 이내 수정도 주체·긍정/부정·조건을 뒤집을 수 있어, 새 서버 결과 서명 없이 바뀐 핵심 내용을 검증할 수 없다. 정규화 정확 일치와 마침표 등 동등한 조판 차이는 허용하지만 단어가 바뀐 글은 자동 보정하지 않는다. 이는 기존 유사 일치 적용률이 낮아질 수 있는 명시적인 트레이드오프다.

캐시는 계속 보정 전 결과만 저장하고 새 요청에 현재 보정 설정을 적용한다. 과거 저장 점수·버전은 소급 갱신하지 않는다. 새 결과 명칭은 “AI식 문체 점수 · N/100”; AI 작성 확률이나 외부 검사 통과 확률이 아니다. 보정으로 인한 하락을 순수 문체 개선으로 표현하지 않는다.

독립 통계의 새 수치 매핑은 도입하지 않는다. 새 독립 검증 자료가 부족하므로 숫자 기여를 OFF로 유지한다. 단, 실제 문장 근거와 결합된 기존 통계 승격은 별도 출처를 표시하며 유지한다.

총 승인 10,000원, 호출 가능액 8,000원, 환율·실패 여유 2,000원. 보수적 관리 환율 2,000원/USD로 $4까지 호출 전 예약한다. 최대 출력과 입력 상한, 캐시 쓰기 단가까지 예약하고 응답 토큰으로 정산한다. 사용량이 불명인 실패는 0원으로 놓지 않고 예약 전액을 유지한다. 이는 청구서의 확정 원화 금액과 다르다.

기본 6·고급 4·다듬기 2의 동일 입력 비교, 대표 감지 6개 입력의 3회 반복 비교, 별도 작성 경위 대조군을 구분한다. 초기 후보에서 재현한 잔여 오류도 숨기지 않는다. 수정 후 국소 단계 재심사와 전체 엔진 재실행은 서로 다른 검증 범위로 기록한다. 소표본으로 전체 정확도나 운영 p95를 주장하지 않는다.
