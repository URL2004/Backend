# 사람 글 대조 평가에 따른 엔진 보완

## 반영 범위

- 감지 v1.28: 모델 선택과 점수 계산을 마친 뒤, 실제 입력 문장 수로 분석 근거 충분성의 상한을 적용한다. 4문장 미만은 low, 4~7문장은 최대 medium이다. 원점수·원인·모델 선택·재검사 조건은 바꾸지 않는다. 이 상한은 작성자 판정 확률이 아니다.
- 휴머나이징 v2.5.47: 원문 종결체가 unknown일 때 register_shift를 발생시키던 잘못된 비교를 수정한다. 원문 종결체를 실제 식별한 plain/polite/haeyo의 변경, 화자·인용·구조 검사는 유지한다.
- 짧고 종결체를 식별하지 못한 글에는 감탄·평가 강도·구어체·명사형 끝맺음을 불필요하게 평탄화하지 않도록 프롬프트를 보강한다. 사용자가 요청한 목표 문체를 우선한다.
- 감지 점수 프롬프트 후보는 개발 평가에서 AI 검출률이 악화되어 반영하지 않는다. 통계 모델 가중치와 적용 범위도 유지한다.

## 자료와 평가 경계

신규 한국어 자료 13,865행의 길이·해시·입력 적합성을 로컬에서 검사했다. NSMC 8,865행과 KorQuAD 961행은 공식 배포본 원문과 모두 일치했다. 원본 문서 및 근접 중복 묶음으로 분리하고, 기존 대조 자료와의 일치·주제명·근접 중복을 검사했다. 근접 중복은 문자 TF-IDF 최근접 검색에 의한 근사 검사이며 완전한 중복 배제를 뜻하지 않는다.

- NSMC: CC0, 짧은 영화 후기. 원문 평가와 휴머나이징 평가에 사용.
- KorQuAD: CC BY-ND 2.0 KR, 원문 문맥 평가만 수행. 재작성·가중치 학습에 사용하지 않음.
- koSentences: GFDL, 원본 문서 묶음이 없는 전처리 행이므로 탐색 평가로 분리.
- PERSUADE 영어 학생 에세이: CC BY-NC-SA 4.0. 상업 서비스에 사용할 권한이 확인되지 않아 외부 모델 평가·학습에서 보류.

출처 기반 사람 글 대조군이며 개별 작성 과정을 직접 인증한 정답은 아니다. 원문·CSV·로컬 실행기·개별 결과는 저장소에 포함하지 않는다.

자료 출처: [NSMC](https://github.com/e9t/nsmc), [KorQuAD](https://korquad.github.io/category/1.0_ENG.html), [koSentences](https://github.com/cynthia/kosentences), [PERSUADE](https://github.com/scrosseye/persuade_corpus_2.0).

## 기존 감지 평가

고정한 464편과 반복 20회를 실제 운영 모델 구성으로 평가했다. 결과 캐시·이력 보정은 제외하고 현재 통계 지원 설정을 사용했다. 평가 표본 SHA-256은 `c0635404357ad3411e7bae7f7541f430ca2ec63aca4207d37dc62ed49456bc83`이다.

| 대조군 | 수 | 21점 이상 | 50점 이상 |
|---|---:|---:|---:|
| NSMC 개발 | 120 | 3 | 0 |
| NSMC 검증 | 120 | 4 | 0 |
| KorQuAD 개발 | 69 | 29 | 4 |
| KorQuAD 검증 | 70 | 26 | 1 |
| koSentences 탐색 | 80 | 0 | 0 |

별도 통계 스트레스 5편에서 1편이 34→51점으로 올라갔다. 표본 선택이 통계 양성에 편향되어 있으므로 일반 오탐률 분모에 합치지 않는다. 주 대조군에서는 통계 보강이 적용되지 않았다.

검증군의 50점 이상 비율과 Wilson 95% 구간: NSMC 0/120(0~3.10%), KorQuAD 1/70(0.25~7.66%). 0건 관찰을 실제 오탐률 0%로 해석하지 않는다. 반복 검사 평균 절대 점수 차이는 NSMC 2.3점, KorQuAD 6.2점이며 KorQuAD 10쌍 중 1쌍이 50점 경계를 넘나들었다.

기존 결과 484개에 근거 충분성 상한만 재적용한 결과 confidence 9건이 수정되고 점수·원인은 모두 동일했다. 실제 엔진 통합 시험도 추가 호출 없이 최종 confidence만 제한되는 것을 확인한다.

## 점수 프롬프트 후보: 미채택

구체적 이름·숫자·경험·오탈자를 사람 작성의 증거로 오해하지 않게 하고, 필요 용어·평서 어미·과제 목차를 AI 원인으로 중복 계산하지 않게 하는 후보를 동결했다. 독립 주제에서 Luna/Terra가 새로 쓴 80편은 사람 표본 길이의 85~115%에 맞춰 생성·길이 조정을 완료했다. 제한된 원문을 재작성하지 않았다.

개발군 사람 40편·AI 40편에 대해 기존/후보를 각각 실행했다. 50점 기준 사람 오탐은 2/40→0/40이지만 AI 검출은 12/40→3/40(30%→7.5%)이었다. 21점 기준 AI 검출도 21/40→7/40으로 줄었다. 사전 기준인 사람 오탐 비증가 및 AI 검출 +5%p를 충족하지 않아 후보는 채택하지 않았고, 새 AI 검증군은 평가하지 않았다.

사용자가 AI 작성이라고 확인한 탐구 보고서는 별도 개발 실패 사례다. 기존 반복 점수 8/8/27, 후보 9/12/14로 여전히 50점 미만이다. 이 사례의 누락은 해결됐다고 주장하지 않는다. 공개 설명문·짧은 후기의 결과를 실제 과제·자기소개서 전체로 일반화하지 않는다.

## 휴머나이징 평가

원문 사용이 가능한 NSMC 개발 8편·별도 검증 8편을 기존/후보에서 각각 실행했다. 사용자 탐구 보고서도 별도로 전후 실행했다. 생성 결과는 로컬에서 원문과 나란히 검토했다.

| 항목 | 개발 기존→후보 | 검증 기존→후보 |
|---|---:|---:|
| 잘못된 unknown 종결체 경고 | 3→0 | 2→0 |
| 실행 실패 | 0→0 | 0→0 |
| 처리시간 중앙값(초) | 9.21→6.66 | 7.00→5.71 |
| 처리시간 최대/95백분위(8편, 초) | 41.56→32.88 | 16.16→36.90 |

말투 경고 제거는 판단 근거가 없던 비교를 바로잡은 효과다. 경고 감소 자체를 문장 품질 전체의 개선율로 계산하지 않는다. 후보의 주요 평가 방향과 숫자는 검토 범위에서 유지됐지만, 문구 압축·감정 강도 변화·고유명사 추정 교정 같은 위험은 남는다. 작은 단회 표본이고 생성 변동성이 있어 처리시간 단축을 보장하지 않는다. 개발 표본 1편은 기존·후보 모두 원문과 동일했다.

## 남은 병목과 검증

짧은 후기 240편 중 194편(80.8%)이 상위 모델 재검사를 거쳤다. 입력 부족에 따른 low와 모델 재판정이 필요한 low가 같은 경로로 처리되는 비용 병목이다. 이번에는 점수 선택을 바꾸지 않기 위해 재검사 경로를 유지했다.

감지 484회의 사용량 추정 비용은 약 $1.4554다. 휴머나이징 후기 32회는 약 $0.2228이며, 생성·다른 비교·사용자 사례·운영 검증 비용은 별도다. 공급자 최종 청구 금액이 아니다.

백엔드 회귀 테스트 1,394개가 통과했다. 실제 식별 가능한 종결체 변경과 화자 추가 경고, 근거 상한 경계, 점수 불변, 추가 모델 호출 방지 회귀를 포함한다. 배포 버전 및 실제 운영 요청·차감·재전송 검증은 외부 운영 보고서에 기록한다.

이력 보정 표시, 크레딧 정책, 비포·애프터, 구조 개선 옵션, 사용자 실행 취소·중단 기능은 이 변경의 대상이 아니다.
