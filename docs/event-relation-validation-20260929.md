# 배타 범위·경험 조건·목적 관계 후속 수정

## 원인과 수정

기존 공통 의미 보존 지침은 관계 보존을 요구했지만 초기 심사의 명시적 질문에는 세 관계가 빠졌다. 배타 검사는 일부 원인 명사와 결합한 형태만, 목적 검사는 제한된 명사형 전환만 다뤘다. 유창한 문장으로 바뀐 관계 오류가 초기 빈 판정에 가려져 최종 심사에서 발견되면 남은 복구 시간도 부족했다.

관계 후보 v21은 같은 행동에 붙은 배타 한정, 경험적 발견의 조건화, 목적의 동시 행동화를 명시적 검토 대상으로 연결한다. 단어 목록 전체 개수 대신 대응 문장의 동일 술어와 유일한 소유권을 확인한다. 인용·코드는 제외하고 요청 내부 구문 캐시를 공유한다. 후보는 오류 확정이 아니며 문맥상 정상 의역은 preserved로 허용한다. 무응답/불확실 답변은 정상으로 처리하거나 자동 복구하지 않는다.

생성과 국소 복구가 공유하는 의미 보존 계약에도 동일 관계 지침을 추가했다. 별도 생성 프롬프트에 중복 삽입하던 초기 시안은 장르별 길이 검사에서 실패해 제거했다. 기존 공통 계약 경로에 통합했으며 테스트 상한·모델·전체 제한시간·과금 정책을 변경하지 않았다. 새 복구 루프를 만들지 않았다.

## 실호출 검증

기존 실제 실패 장문의 원문·결과 전체에서 세 후보가 각각 1개 생성됨을 확인했다. 이후 해당 세 문맥을 실제 모델로 심사·복구·재심사했다. 마지막 실행은 세 문맥 모두 pass, uncertain=false, 복구 1회, 잔여 지적 0이었다. 실행 중 코드는 바뀌지 않았다. 직접 대조에서도 세 관계 복원을 확인했고, 정상 편집과 분리된 문단은 유지됐다.

첫 실행의 경험 조건 문맥은 검증 도구가 정상 분리된 결과의 두 번째 문단을 빠뜨려 누락 4건까지 잘못 유발했다. 이 실행은 통과 근거에서 제외하고 기록을 보존했다. 원문 전체 8문장에 대응하는 두 결과 문단을 함께 읽고 다시 실행해 통과했다. 이는 운영 엔진의 신규 누락으로 집계하지 않는다. 초기 모듈 경로 오류 실행은 모델 호출 전 중단됐으며 비용이 없었다.

이번 후속 비용은 613.13620원, 이전 승인 원장 누적 2,337.27013/3,000원이다. 미확정·예약 0원, 남은 금액 662.72987원. 사용자 크레딧과 운영 DB 변경 없음. 원문과 모델 응답은 저장소 밖 비공개 자료로만 보관한다.

## 검증 범위

새 회귀 8건은 각 관계의 명시 응답, 인용/코드/중복 소유권, 정상 의역, 공통 계약 연결을 검사한다. FLOOR 37사례 88검사 통과, import 278파일 849연결 위반 0. 장문 레이아웃 후속 수정까지 포함한 최종 전체 회귀 2,776/2,776 통과(228.925초). 성능의 운영 p95 측정으로 사용하지 않는다.

이는 실제 실패 문맥의 복구 검증이며 최신 코드로 장문 전체를 새로 생성한 결과는 아니다. 후보 전체의 운영 배포 완료를 의미하지 않는다.
