# GPT-6 Luna / Sol 전환 검증 (2026-09-23)

## 판단과 범위

운영 기준 커밋은 `52048ae`(휴머나이징 v2.5.63, 감지 v1.38)이다.
첨부 비교의 외부 벤치마크 순위를 한국어 서비스 품질 보장으로 해석하지 않았다.
공식 API 모델 ID, Responses 지원, 추론 단계와 요금을 확인하고 기본 모델을
GPT-6 Luna, 기존 Terra 승격 모델을 GPT-6 Sol로 교체한다.
요금·차단·전달 정책, 감지 점수 보정, 프롬프트와 편집 기준은 변경하지 않는다.

| 단계 | 모델 | 추론 | 판단 |
|---|---|---|---|
| 기본·고급·다듬기 생성 | Luna | medium | 문체·정보 보존을 함께 처리 |
| 사실관계가 복잡한 청크 | Luna | high | 기존 고위험 판정에만 적용 |
| 장르 분류·1차 AI 감지 | Luna | low | 한정된 분류·증거 추출, 전면 상향하지 않음 |
| 의미 심사·국소 수리·근거 검색 | Luna | medium | 기존 역할별 강도 유지 |
| 품질 승격·재심사 | Sol | high | 불확실하거나 회복이 필요한 경우 |
| 사용자 승인용 구조 계획 | Sol | medium | 감지 설정과 분리해 판정 모델/강도 사용 |

`none/xhigh/max`도 API에서 지원하지만 기본 사용하지 않는다.
`minimal`은 지원되는 `low`로 정규화한다. 관리자 지정 추론 값은 보존한다.

## 수정 지점

- runtime v3: 환경변수·Firestore의 5.6 Luna/Terra 및 기존 5.4 별칭까지 마이그레이션.
- v1 추론 보정과 v2 모델 마이그레이션 분리: 사용자 지정 강도를 덮어쓰지 않음.
- compat 감지·검색 승격의 모델/추론 불일치 수정.
- 구조 계획의 고정 low를 제거하고 Sol + 판정 medium으로 연결.
- GPT-6은 Responses `prompt_cache_options.ttl=30m` 사용. 구형 `24h`를 전달하지 않음.
- 새 단가·캐시 쓰기 비용·날짜형 모델 ID 비용 정규화. 과거 비용 기록은 재계산하지 않음.
- 감지 결과 캐시 키가 모델·추론을 포함하는 기존 정책 확인: 이전 모델 결과를 재사용하지 않음.
- 운영 설정 적용 스크립트는 기본 dry-run, `--apply`에서만 모델·추론 저장.
  캐시·승격 임계값을 초기화하지 않음.
- 관리자 모델 선택지·기본값·설명을 함께 변경. 과거 패치노트의 모델명은 유지.
