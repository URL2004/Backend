# Korean edit integrity — v2.5.54

문장 재구성 과정에서 원문의 지시 관형어가 빠지거나 비교 어미·명명 구문의 논항 관계가 손상되는 문제를 보완한다. 문단 분리와 정상적인 주변 문장의 개선은 유지한다.

## 변경

- 같은 주어와 충분히 유사한 문장이 원문에 유일하게 대응할 때만 누락된 지시 관형어를 복원한다. 일반 주어, 지시어 동의 표현, 대상 명사의 교체, 모호한 반복은 자동 수정하지 않는다.
- 비교 어미가 비문으로 바뀐 경우, 원문 문장의 유사도와 어미 직전 두 단어까지 확인해 해당 어미만 복원한다. 원문부터 존재한 표현과 정상 조건문에는 적용하지 않는다.
- 주체·대상·명칭이 역전된 명명 구문은 세 요소와 서술어를 대조해 정확히 한 문장만 복원한다. 일반적인 다문장 정렬에 맡겨 앞뒤 문장을 함께 치환하지 않는다.
- 공통 한국어 감사, 결정론적 수리, 최종 전달 단계의 복원에 연결한다. 후속 후보가 같은 오류를 다시 도입하면 기존 후보 무결성 검사에서 거부한다.
- 접속어 정리기가 명사를 수식하는 지시 관형어를 삭제하지 않도록 수정한다. 생성·수리 지침에 지시 관계 보존과 불필요한 도치 억제를 추가한다. 기존 프롬프트 길이·행 수 제한을 유지한다.
- 인용문, 여러 줄에 걸친 인용, 코드, 제목, 목록, 표, 참고문헌은 보호한다. 원문·결과의 문자 위치를 그대로 사용한다.

## 확인 범위

지정된 저장 작업의 원문/결과를 로컬에서 읽기 전용으로 대조했다. 새 수리로 지시어 누락 4곳, 비교 어미 오류 1곳, 명명 구문 오류 1곳을 복원했다. 355개 문장 중 나머지 349개 문장과 98개 문단 경계가 유지됐고, 후보 무결성 검사와 재실행 시 동일 결과를 확인했다. 사용자 원문·식별자·평가 산출물은 저장소에 포함하지 않는다.

합성 예제 회귀 테스트와 모델 응답을 모의한 실제 엔진 전달 테스트를 추가했다. 이 검증은 기존 결과에 대한 재생이며, 외부 모델로 문서 전체를 새로 생성한 품질 평가가 아니다.

검증 결과: `npm test` 1,633개 통과, 실패·건너뜀 0개. 운영 import 검사(219개 파일)와 `git diff --check`도 통과했다.

기존 접속어 과다 경고는 재생 결과에 남는다. 원문부터 쉼표가 없던 제목은 보호 구조로 유지하며, 문법적으로 가능한 강조 구문은 일괄 치환하지 않는다. 불필요한 강조·도치는 생성 지침으로 억제하되 모든 표현의 자연스러움을 결정론적으로 보장하지 않는다.
