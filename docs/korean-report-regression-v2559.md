## 원인과 수정

1. 인용 안의 줄바꿈을 문장 끝으로 세던 경로를 공통 구문 소유권 검사에 연결했다. 인용 뒤 줄바꿈된 귀속 표현도 같은 문장으로 계산한다.
2. 목적어·조건절·부정절이 짧은 제목으로 분류되던 경우를 뒤쪽 서술어까지 확인해 본문으로 분류한다. 입력 전처리와 최종 경계 수리가 같은 판정을 사용한다. 번호 제목·라벨·목록·코드·인용은 기존 보호를 유지한다.
3. 상황 분석에서 대책으로, 초기 경험에서 이후 단계로 이동하는 문단 경계를 양쪽 내용과 문장 수로 판별한다. 전체 140자라는 일괄 제한 때문에 발달된 짧은 글의 전환을 놓치던 문제를 고쳤다. 연결어 하나만으로 분할하지 않는다.
4. 비교 문단의 대상 구분을 개선했다. 같은 대상에 대한 단순 부연이나 짧은 한 문장은 강제로 나누지 않는다. 다듬기·창작·법률의 기존 예외를 유지한다.
5. 참고문헌 등 잠긴 블록을 일반 산문 가독성 목표에서 제외한다. 긴 보호 블록 때문에 정상 본문을 반복 분할하던 순환을 제거하고, 길이 회복은 실제 과장문에만 적용한다.
6. PDF 복사의 Unicode 행 구분을 가로 표 열로 오인하지 않는다. 명시적 탭·파이프 표는 그대로 보호한다.
7. 코드 내부 빈 줄을 일반 문장 경계로 합치지 않는다. 빈 줄로 나뉜 청크의 trim으로 사라진 들여쓰기는 전체 코드 span 소유권에 따라 복원한다. 서로 다른 코드 내용을 불확실한 위치로 옮기지 않는다.
8. 인용 귀속 표현 사이의 빈 줄과 `수있다`, 월+말, 복합 용언+보조 용언의 제한된 문맥형 띄어쓰기를 보완한다. 직접 인용과 코드 내부에는 적용하지 않는다.
