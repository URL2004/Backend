- 가상 경계의 진단 위치는 원문 행으로 환산한다. 명시적 단일 번호와 소수·본문 절 참조를 구분한다.

- PDF 원문의 단어 내부 강제 줄바꿈으로 앞 청크의 접두 조각과 다음 청크의 완성 단어가 중복되는 경우, 원문의 정확한 분할 증거가 있을 때만 접두 조각을 삭제한다. 정상 제목·의도적 반복·인용·코드는 제외한다. 최종 중복 검사와 제거기가 같은 규칙을 사용한다.
- 모델, 추론 강도, 가격, 전달·과금 정책, 동시성, 묶음 활성화 상태는 변경하지 않는다.
