## 원인과 수정

4. **짧은 제목이 본문 대응을 가로채는 검사 결함.** 부분집합 단어 겹침 점수가 같으면 앞의 제목이 본문 대신 선택됐다. 정확히 같은 문장을 먼저 선택하고, 동률은 양쪽 문장 전체의 겹침으로 해소한다. 정렬 대신 최선 후보만 유지한다. 기존 대응 임계값과 12개 후보 상한은 유지한다.
