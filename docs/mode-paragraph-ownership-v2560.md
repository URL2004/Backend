# 모드별 본문 문단 개선 · v2.5.60

기준선: 운영 v2.5.59 / `89e14ba`. 작성일: 2026-09-20.

## 결론

제목·항목이 있는 문서에서 본문 개선을 놓치던 경로와, 개선 후 감사·복원 경로의 정책 불일치를 수정했다. 원문 문단 수 자체는 기본·고급의 최종 목표가 아니다. 사실·인용·제목·항목 소속은 보호하면서 본문 문장과 문단의 가독성을 개선한다. 좋은 문단은 유지하며, 변화량을 만들기 위해 모든 문단을 강제로 나누지는 않는다.

## 원인과 수정

1. 모델의 중간 문단 앵커 보존 지시가 최종 문단 수 보존으로 읽힐 여지가 있었다. 문장 분리·결합과 절 배치는 허용하되 내용 소속을 고정하고, 최종 본문 문단은 레이아웃 단계의 책임임을 공통 계약·문체 프롬프트에 명시했다. 사실 소유권과 의미 검증은 유지한다.
2. 기존의 넓은 재배치 경로는 고급 서사형에 제한돼 있었고, 항목형 본문 분리는 길이와 일부 연결어에 의존했다. 문장 내 활동의 역할과 전후의 발달된 내용을 함께 보고 전환을 찾는다. 특수 연결어 한 개만으로 분할하지 않는다. 특징은 본문 구간마다 한 번 계산한다.
3. `none+block_semantic_roles`처럼 결합된 레이아웃 정책명이 문체 감사에서 인식되지 않았다. 승인된 정책들의 조합만 인식하게 하고 최종 문단 수를 감사에 전달한다. 일반 경고를 통째로 해제하지 않는다.
4. 고정점 반복의 마지막 무변경 회차가 이전 개선 정책·횟수를 0으로 덮었다. 실제 개선 회차의 정책과 횟수를 보존하고 최종 전달본의 문단 수·가독성으로 메타데이터를 갱신한다. 같은 수리를 반복한 횟수를 합산해 부풀리지 않는다.
5. 구조 개선의 승인된 배치를 일반 본문 분리기가 다시 나누면 전달 검증에서 거절돼 구조 없는 재실행으로 돌아갈 수 있었다. 승인된 계획을 별도 `approved_plan` 권한으로 연결하고 후처리의 추가 분할·원래 배치 복귀를 금지했다. 기존 승인·범위·내용·전달 검증은 그대로 수행한다.
6. 문장 안의 책 제목·짧은 인용 때문에 문단 전체가 구조 개선 대상에서 제외되던 과보호를 제거했다. 인용·코드 내부의 분할은 거절하고 해당 span의 줄바꿈은 그대로 유지한다. 독립 인용·표·목록·제목·참고문헌은 기존 보호를 유지한다.
7. `‘검증’을`처럼 한국어 조사와 붙는 인용 닫힘을 영어 아포스트로피로 오인하던 공통 구문 분석을 수정했다. 중첩 인용의 역할 단어가 본문 전환 신호로 새어 나오지 않으며, 인용 뒤 실제 본문을 잘라 먹지 않는다. 영어 don't / don’t는 유지한다. 문장 중간 줄바꿈 수리도 인라인 인용이 있다는 이유만으로 행 전체를 잠그지 않는다.

## 모드별 책임

| 모드 | 적용할 개선 | 유지할 경계 |
| --- | --- | --- |
| 기본 | 같은 항목 안의 명확한 내용 전환·결과/성찰 구분과 가독성 정리 | 항목 순서, 사실 소속, 제목·표·인용 |
| 고급 | 기본의 개선 + 동기/기획→실행→검증→결과/성찰의 더 세밀한 구분; 기존 서사형 재구성도 유지 | 항목·사실 소속, 인과·시간 관계, 보호 구조 |
| 고급 + 구조 개선 | 기존 미리보기에서 검증하고 사용자가 승인한 이동·합침·분리를 적용; 일반 후처리가 이를 덮어쓰지 않음 | 승인 범위, 고정 제목, 절·보호 경계, 전체 내용 커버리지 |
| 다듬기 및 고정 형식 | 기존 보수적 정책 유지 | 다듬기·창작·법률·임상 및 명시적으로 모든 행을 보호하는 형식 |

구조 개선 미리보기의 기존 장르 적격성·권한·비용은 바꾸지 않는다. 구조 계획은 v2로 갱신하므로 배포 전 v1 미리보기는 기존 stale-plan 처리에 따라 새로 요청해야 한다. 안전하지 않은 계획을 억지로 적용하지 않는다.
