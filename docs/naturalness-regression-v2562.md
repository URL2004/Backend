# v2.5.62 — 변경량 중심 재표현으로 생기는 자연성 퇴행 보강

작성일: 2026-09-20. 기준: `115b25f` / v2.5.61.

## 확인한 원인

생성 계약은 자연스러운 문장 유지를 지시하면서도 최소 수정 문장 수와 어순
변화를 요구했다. 문제 표현이 없어도 재구성을 요구하는 분기와 재시도에서
최소 두 문장을 바꾸라는 지시도 남아 있었다. 이 지시 충돌은 확인했지만,
사용자가 제공한 실제 작업의 어느 호출이 문제 문장을 생성했는지는 확정하지 않았다.

한국어 감사의 기존 명사화·조건문 규칙은 일부 어휘 유형만 포괄했다. 원문에
없던 행동 명사화, 목적문을 조건+희망으로 바꾼 문장, 격식문 수식어 도치에
대한 대응 검사가 필요했다. 이번에 추가한 검사는 단어 금지가 아니라
원문–결과의 명확한 문장 대응이 있을 때만 작동한다.

## 변경

1. 생성·문서 회복·단문 회복에서 변경량보다 의미·호응·자연스러움을 우선한다.
   기존 수치 목표는 검토 범위로 설명하며, 문제 구간은 충분히 재작성하되
   정상 문장을 억지로 늘이거나 도치하여 개수를 채우지 않는다.
2. `naturalnessRegression`에서 새 행동 명사화, 새 조건–희망 연결,
   격식문에서 수식어가 끼어드는 제한된 도치 유형을 원문과 대조한다.
   일반 어순 변화와 창작문 강조를 일괄 오류 처리하지 않는다.
3. 같은 행동·시제·의향이 확인되는 명사화는 해당 구절만 복구한다.
   시작 명사화는 동일한 두 어절 목적어·조사·직접 서술어의 원문 근거가
   확인될 때만 국소 복구하며, 나머지는 기존 모델 수리로 검토한다.
4. 기존 후보 무결성 검사에 연결되어 늦은 재작성 후보가 같은 오류를 새로
   만들면 채택하지 않는다. 이는 작업 차단 정책 추가가 아니다.
5. 새 퇴행이 발견된 경우에는 기본 단문에서도 기존 의미 심사가 실행된다.
   국소 복원만 했다는 이유로 심사를 생략하지 않는다.

모델, 가격, 전달·과금 정책, 편집률 계산식·임계값, 문단 권한 및 감지 엔진은
변경하지 않는다. 프롬프트 길이 상한도 유지한다. 사용자 원문이나 인용 내용은
새 관측 필드에 저장하지 않는다.

  실제 지속·시작 의미, 기존 원문 표현, 조건문 정상 사례, 인용·코드,

## 제한

모든 부자연스러운 문장을 포괄하는 문법 판정기는 아니다. 확신이 낮은 대응은
수리하지 않으며, 수식어 도치는 문맥 판단이 필요한 검토 항목이다.
원문의 주장 범위·빈도 표현을 근거 없이 축소하거나 새 사실을 보충하지 않는다.

실제 유료 모델 재실행은 포함하지 않았다. 추가 모델이 생기는 것은 아니지만,
새 퇴행 검사가 기존 의미 심사를 실행하게 하는 요청에서는 비용·시간이 늘 수 있다.
운영 적용 후에는 해당 심사 사유와 수리 결과를 확인해야 하며, 로컬 성공을
모든 실문서의 자연스러움 개선 또는 무재발 보장으로 해석하지 않는다.
