# 의향·반복 조건 심사 후속 검증 — 미배포

앞선 semantic-adoption-release-candidate-20260929.md 이후의 별도 검증 기록이다. 앞선 비용과 이번 승인액을 합산하지 않는다.

## 변경

관계 후보 v20은 조건절 전체가 의역돼도 같은 희망 행동 접두 구간이 양쪽에서 유일하고 조건절 소속이 명확하면 반복 표현 추가를 심사 질문으로 전달한다. 보호 구간, 다중 조건·행동, 모호한 소유권은 제외한다. 후보는 자동 오류 확정이 아니다. 기존 의향/희망 후보와 감사 요청 내부의 지연 구문 캐시도 검증했다. 모델·과금·전달·제한시간 정책은 변경하지 않았다.

## 검증 결과

- 전체 순차 회귀 2,764/2,764, FLOOR 37사례 88검사, import 277파일 846연결 위반 0.
- 초기 병렬 전체 검사에서 성능 기준 1건 실패(2,760건 통과). 단독 성능 검사 17/17 및 최종 전체 순차 검사 통과. 기준을 낮추지 않았으며 초기 실패 기록도 보존했다.
- 독립 안전 검토 22/22 통과. 인용·코드 보호와 모호한 조건의 배제 확인.
- 합성 문서의 동일 후보 출력 유지: 보호 구간 분석 요청 280회에서 2회. 운영 지연 개선율로 일반화하지 않는다.
- 이전 실제 의향/희망 오류 2건을 초기 심사에서 발견하고 복구. 같은 문단의 별도 비교 오류가 남아 전체 문단은 실패 유지.
- 실제 반복 조건 사례는 문맥에 이미 반복이 함의돼 정상 판정. 무조건 오류로 강제하지 않았다.
- 최소 합성 사례는 오류 검출 후 원문 전체 복귀 가드에서 거절. 정상 편집을 포함한 별도 대조군에서는 배타 범위와 반복 조건 2건 복구 후 실제 재심사 통과, 정상 편집 유지.

## 장문과 배포 제한

8,689자 전체 새 생성·복구·최종 심사는 v19에서 실제 실행했다. 저장 응답 재생이 아니다. 최종 대상과 반환문 일치, 양쪽 최종 감사 완료. 그러나 배타 범위 추가, 과거 발견의 조건화, 목적 관계의 동시 행동화 3건이 남아 실패했다. 마지막 심사 뒤 기존 복구·재검증 창의 시간이 부족했다. v20의 문단 실호출 성공을 장문 전체 성공으로 확대하지 않는다.

따라서 통합 후보는 미배포다. 최종 실패를 억제하거나 미검증 결과를 통과로 표시하지 않는다.

## 예산·개인정보

이번 별도 3,000원 승인 내 32회 HTTP 호출, 보수적 환율 환산 1,724.13393원. 미확정·예약 0원, 미사용 1,275.86607원. 사용자 크레딧과 운영 데이터 변경 없음. 실제 원문·결과·호출 기록은 저장소 밖 비공개 자료로 유지한다.
