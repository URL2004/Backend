# v2.5.51 문단·문장 무결성 보강

기준: 23a3624 / v2.5.50. 2026-09-14 한국 시간.

## 수정

- 접속형 어미·쉼표로 끝난 산문을 제목으로 잠그지 않는다. 전처리·청크·최종 경계 수리에 같은 판정을 사용한다.
- 제목 다음의 지시어 `이`를 떨어진 조사로 붙이지 않는다. 기존 OCR 조사 복원은 유지한다.
- 의미 심사에서 누락이 확인된 경우, 원문의 유일한 미완성 절 접두부와 정확히 대응하는 문장만 복원한다. 새 경험은 생성하지 않으며 포괄적인 의미 경고를 임의로 삭제하지 않는다.
- 제목이 있는 자소서도 각 완결된 경험 행을 독립 읽기 단위로 보존하고 내부의 긴 문장은 문단화한다.
- 보조 안전 프로필은 사실·화자 감사를 넓히는 데 사용한다. 자소서의 보조 분류가 자기평가라는 이유로 전체 행 고정 정책을 덮어쓰지 않는다. 실제 관찰·자기평가 문서의 기존 행 보호는 유지한다.
- 반복적인 수강·강연 회고가 있고 직접적인 지원서 구조가 없는 글을 직무 키워드만으로 자소서로 오인하지 않는다.
- 최종 전달 문자열의 미완성 문단 후보 수·새 후보 수·최대 문단 길이를 원문 없이 기록한다. 후보 수는 확정적인 오류 판정이나 새로운 차단 조건이 아니다.

## 검증

- 전체 자동 테스트 1,556개 통과. 제목/OCR, 연결 절, 누락 복원, 제목+자소서, 보조 프로필 정책 충돌, 최종 지표, 감지 반복 평가 회귀 포함.
- 후속 운영 53쌍을 최신 프로필·행 정책으로 레이아웃 재생: 비공백 문자 보존 및 재적용 고정점 53/53. 구조 통과 52/53. 나머지 1건은 이전 결과에서 이미 제목이 사라진 문서이며, 레이아웃만으로 내용을 추가해 통과시키지 않았다.
- 중점 5문서 실제 모델 실행과 수정 후 추가 3회 실행. 최초 장문 실행에서 전체 행 고정과 문단화의 충돌을 재현하고 수정했다. 최종 장문 재실행은 구조 통과, 되돌림 0, 새 미완성 문단 후보 0, clean으로 전달됐다.
- 제목 손실 사례와 짧은 시놉시스도 최종 v2.5.51 실호출에서 구조 통과·새 미완성 문단 후보 0 확인.
- 결제·차단 정책, 모델 선택, 입력 원문 저장 정책은 변경하지 않는다. 이미 저장된 사용자 결과를 소급 수정하지 않는다.

## AI 감지: 해결되지 않은 반복 편차

이전 44건의 점수/표시 불일치는 없었다. 최소 표현 변경쌍을 모델에 각 3회 직접 호출하면 원문 58·46·36점, 변경문 43·42·55점이었다. 동일 원문 안의 변동 폭이 각각 22·13점이므로, 표현 변경의 영향만으로 설명할 수 없다. 동일 입력 캐시를 우회한 모델 판정 측정이며 운영 캐시 자체가 실패했다는 뜻은 아니다.

`evaluateMinimalEditStability`는 동일 입력 반복 편차와 의미 보존 편집 민감도를 구분하고, 의미를 바꾼 대조군에 점수 동일성을 강제하지 않는다. 평가 통과만으로 배포를 승인하지 않는다.

감지 점수 정책과 v1.32 버전은 유지한다. 점수를 임의로 낮추거나 서로 다른 입력의 캐시를 합치지 않았다. 반복 편차 자체의 개선은 장르별 정답 표본·반복 호출·오탐 검증을 갖춘 후속 과제이며 이번 배포로 해결 완료라고 주장하지 않는다.
