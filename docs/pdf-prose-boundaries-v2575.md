## 수정 내용

- PDF 형태로 복사된 글에서 반복된 행 너비, 미완성 문장, 확인 가능한 어절 연결이 함께 나타날 때만 물리적 행을 문장으로 연결한다. 제목·목록·표·코드·직접 인용·참고문헌은 경계로 유지한다. 비공백 문자는 추가·삭제하지 않는다.

- 인용문 안의 마침표 뒤에 붙은 한국어 조사를 새 문장의 시작으로 오인해 공백을 넣지 않는다. 실제 다음 문장과 코드 보호는 별도로 검증한다.
- 마침표가 생략된 명확한 종결문과 구문상 동일 괄호에 속하는 날짜의 물리행 연결을 보완한다. 일반적인 짧은 행·다른 날짜·서지 항목을 추측해 합치지 않는다.
- 부분 누락의 대응 문장이 결과에 남아 있는 경우, 문장 전체 누락 복구로 넘어가 중복 삽입되지 않도록 한다. 해당 부분의 복구 및 최종 의미 재검증은 기존 대응 구간 경로에서 수행한다.
- 같은 요청에서 앞서 확인한 의미 오류는 현재 원문·결과의 대응 구간이 정확하고 유일하게 남아 있을 때에만 최종 국소 복구 후보로 유지한다. 심사기가 반환한 순서가 아니라 실제 원문 순서로 처리하며, 이전 판정을 새 통과 판정으로 재사용하지 않는다. 복구 범위·인용·구조 보호와 새 의미 재검증은 유지한다.
- 거절된 중간 복구본의 재심사 지적도 공식 판정과 분리해 요청 내부 후보로만 유지한다. 정확히 대응하는 왜곡·누락·대상 범위 확대는 공용 타입 목록을 사용한다. 최대 8개 구간·문서 30% 상한을 유지하며, 기존 유사도 기반 복구의 4개 상한은 변경하지 않는다. 이 내부 후보 기록은 응답과 원장에 추가 노출하지 않는다.
- 그래프 캡션·연속 숫자 축·가로 축의 결합을 본문 문단으로 취급하지 않는다. 구조 계획 적용 시 축 숫자가 제목에 붙지 않도록 행을 보호한다. 새로운 블록 소유권과 구형 승인 계획을 구별한다.
- 긴 그래프 캡션도 물리행 전처리 단계부터 동일한 역할 판정으로 보호한다. 앞의 미완성 본문에 붙은 뒤 그래프로 잠기는 단계 간 충돌을 방지한다.
