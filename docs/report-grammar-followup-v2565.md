# v2.5.65 탐구·성찰문 후속 회귀

2026-09-24 · 운영 미반영 검증 후보

## 원인과 변경

1. 인용부호 뒤 비교 서술격 표현의 공통 목록에 `이라기보다/라기보다` 변형이 없었다. 감사와 교정기가 같은 목록을 사용하도록 보완했다. 정상 문장에 공백을 다시 넣지 않도록 멱등성을 검사한다. 코드·중첩 인용 내부는 수정하지 않는다.
2. 원문 판단 근거인 `조사를 통해`를 `조사에서는`으로 바꾸어 내포절의 주제와 겹치는 사례를 감사하지 못했다. 명확한 원문 대응이 있고 근거 관계가 확인되는 경우에만 해당 접두 구간을 복원한다. 은/는의 반복을 일반적인 문법 오류로 취급하지 않는다.
3. 원문의 인식 과정이 결과에서 무생물의 행위로 바뀌는 성찰문을 놓쳤다. 원문 한 문장이 결과 두 문장으로 나뉘면 전체 문장 유사도가 다른 일반 문장을 더 높게 평가할 수 있었다. 고유한 명제 끝부분과 원문의 경험 서술어가 모두 일치할 때만 해당 서술어를 복원한다. 공통 정렬 기준을 낮추지 않는다.
4. 두 신규 의미 관련 교정은 기존 필수 의미 검증 대상에 연결했다. 품질 경고·전달·과금 정책은 변경하지 않는다.

## 검증과 한계

- 전체 자동 회귀 1,901개 통과, production import graph 위반 0건.
- 신규 단위 회귀 6개와 고급 엔진 통합 회귀 1개. 비교 어미 20조합, 멱등성, 코드·중첩 인용, 정상 대조, 근거 부족, 중복 근거, 일대다 문장 대응을 포함한다.
- 직전 수정 커밋을 기준으로 과거 579쌍을 재생했다. 추가 텍스트 변화는 1쌍이며, 혼합 인용부호 내부에 넣던 잘못된 공백을 막은 변화였다. 변경 구간을 직접 대조했다.
- 첨부 사례의 감사 누락 3종을 재현하고 교정 후 해당 경고 0건을 확인했다. 실제 모델의 의미 재심사도 통과했다. 신규 생성 실험이 아닌 기존 결과의 수정 후보 검증이다.
- 이전 실호출을 포함한 동일 예산 원장의 누계는 약 4,192원(보수적 환율과 20% 여유 포함)이다. 사용자 크레딧은 차감하지 않았다.
- 원문 자체의 과도한 문단 분절까지 모두 해소한 것은 아니다. 긴 인용 질문 앞뒤의 원래 분절 일부는 유지되며, 이 패치를 전체 문단 재구성 해결로 발표하지 않는다.
- 앞선 장문 지연 수정은 동일 응답의 구조 오탐 해소, 장문 생성 1건 및 수정 후보 의미 재심사로 검증했다. 최종 패치 전체를 적용한 별도 장문 신규 생성과 운영 p95 검증은 아직 수행하지 않았다.

사용자 원문·결과·식별자·실호출 원장은 저장소에 포함하지 않는다. 본 문서는 배포 완료 기록이 아니다.
