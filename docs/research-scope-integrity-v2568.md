# 원문 대비 신규 오류 무결성 보강 — v2.5.68 / 감지 v1.42

## 범위와 판정 원칙

2026-09-25 기준 직전 추출 경계 이후 휴머나이징 97쌍을 전문 직접 대조하고 별도 모델로 교차 검수했다. 여러 과거 엔진 버전이 섞인 모집단이므로 97건을 현재판의 실패율이나 개선판의 성과로 발표하지 않는다. 원문부터 있던 문제, 새 오류, 표현 취향, 자료 부족을 구별했다. 사람 블라인드 평가나 외부 사실 인증은 아니다. 운영 감지 52건은 공통 문장 입력의 위치 정합성만 재생했다. 감지 점수의 정확도 실험은 아니다.

원문·결과·UID·실호출 자격증명과 비공개 검수 파일은 커밋하지 않는다. 문단 보강 2건은 승인 메모 원문이 남아 있지 않아 추가 내용이 허용된 것인지 확정할 수 없다. 과거 PDF 원본도 없으므로 표 행·열의 임의 복원은 하지 않는다.

## 검증

- 신규 재현은 합성 비개인 문장을 사용한다. 양성 사례뿐 아니라 정상 인용·소수점·가족 서열·실제 중국어/일본어·반복이 원문에 있는 경우·정상 1:1 편집도 검사한다.
- 백엔드 2,006/2,006 테스트 및 production import graph 통과. 프런트 345개 통과·1개 조건부 제외·실패 0, 저장소 밖 프로덕션 빌드 통과. 프런트는 관리자 패치노트와 관련 버전 검증만 변경한다.
- 97건 로컬 표면 수리 재생에서 6건 변경, 인용·코드·수치·구조 표지의 신규 손실 0건. 52건 감지 입력 위치 일치. 이는 97건의 전체 모델 재실행과 다르다.
- 실호출은 운영 모델 설정을 읽어 동일 엔진을 직접 호출하며 사용자 크레딧·이력을 수정하지 않는다. 전체 5,000원 상한 안에서 호출 전 보수적 예약, 실패·재시도 포함 정산, 불명 비용 예약 유지.
- 초기 실호출에는 검증 도구의 8분 제한을 적용했다. 운영 기본 제한과 다르므로 시간 예산 관련 실패는 스트레스 검증으로 구분한다. 마지막 장문 재검증은 운영 시간 설정을 그대로 사용하며, 외부 검증 도구만 15분에 취소한다. 운영 시간·호출·비용 상한을 변경하지 않는다.
- 긴 논문의 첫 재실행은 새 결론 중복 때문에 실패로 기록했다. 수정 후 재실행에서 중복과 최종 의미 검증을 확인했고, 전문 직접 검수로 쉼표 없는 첫 열거 누락을 추가 발견해 다시 수정했다. 모델 PASS만으로 출시 합격하지 않는다.
- 코드 문서, inline 목록, 독후감 라벨, 한글 열거/학술 인용, 연구 범위 복구는 실호출에서 해당 재현 개선을 확인했다. 긴 논문 및 접두사 문법 수정의 최종 전달본 검증은 아직 완료하지 못했다. 중간 생성 응답만 정상인 경우 합격으로 처리하지 않는다.
- 379회 HTTP 요청에는 97건 독립 검수와 생성·심사·실패·재시도가 포함된다. 확인 사용량의 보수적 환산 약 3,077원과 미확정 실패 예약 약 1,509원을 합쳐 4,587원으로 관리했다. 실제 청구액 확정치가 아니며 다음 호출이 한도를 넘길 수 있어 중단했다.
- **추가 승인 후 최종 장문 검증 완료:** 추가 5,000원 승인 후 누적 10,000원 범위에서 14,743자 문서 전체를 운영 모델·시간 설정으로 다시 실행했다. 398.753초, 승인 청크 26개·실패 0, 최종 정확한 후보의 의미 검증 pass/exact 및 qualityStatus=clean. 전문 직접 대조에서 의의 1~5번과 한계 1~9번, 통계 수치·집단 귀속·연구 한정 조건이 유지되고 이전 번호 접합·결론 중복이 재현되지 않았다. 수치 멀티셋 차이 0. 빈 줄 단위는 제목 포함 88→92이며 개수 자체를 품질 점수로 사용하지 않는다.
- 이 실행에서 실제 의미 수리와 수리 후 재심사·최종 후보 재검증이 수행됐다. 초기 심사가 찾은 교육내용/교육과정의 범위 차이와 제언의 강도 변경을 수리했다. 43회 HTTP 호출 비용은 실패 예약 포함 보수적 약 315원, 누적 약 4,902원이었다. 이전 실패는 성공으로 덮지 않고 별도 기록한다. 첫 문장 어순과 말미의 같은 종결 반복 등 추가로 다듬을 문체 여지는 남아 있으며, 모든 문장의 자연스러움이나 장문 전체 모집단의 성능을 보장하는 수치가 아니다.

## 유지 정책과 제한

모델·요금·전달·과금 정책, 일반 호출 및 회복 동시성은 변경하지 않는다. 품질 미달 차단을 추가하지 않는다. 감지 점수를 낮추는 임의 보정도 없다.

모든 문장 자연스러움의 개선을 보장하지 않는다. 화자의 성찰이 일반 명제로 평이해지는 경우, 새 조사/연어의 문맥 의존 오류, 장문의 주제 단위 문단 구성, 이미 추출 단계에서 손상된 표는 잔여 위험이다. 근거 없는 강제 교정 사전이나 임의 내용 복구로 처리하지 않는다. 이번에 확인한 구조 결함과 문맥 심사 후보 개선을 구분해서 운영 관측한다.

최종 의미 검증 미완료 결과를 검증 완료로 바꾸지 않으며, 기존 결과·과금은 소급 변경하지 않는다. 신규 의미·구조 훼손 또는 미검증 결과의 정상 표시가 발견되면 직전 live `80e7543`으로 복귀한다.
