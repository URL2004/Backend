# 장문 학술 문서의 단일 개행·논점 경계 복원

## 원인

최근 학술 원문은 완결된 본문 단위 사이에 빈 줄 대신 단일 개행을 사용했다. 결과에는 서로 다른 이론 설명 두 단위가 1,061자 한 행으로 합쳐진 부분이 있었다. 기존 sourceParagraphTransitions는 빈 줄만 원문 문단으로 해석했고 전체 출력 180문장 상한 때문에 이 문서(결과 322문장)를 건너뛰었다. 이후 가독성 정리는 길이를 줄였지만 실제 논점 전환 경계는 복원하지 못했다. 따라서 총 문단 수나 가독성 pass만으로 해당 경계 보존을 확인할 수 없었다.

## 변경

동일하고 유일하며 순서가 연속으로 대응하는 제목 사이만 독립 정렬 범위로 취급한다. 각 범위에서는 기존 readable paragraph 판정으로 완결된 단일 개행 본문도 읽기 단위로 인식한다. 양쪽 인접 문장의 기존 유사도·모호성 기준을 유지하며, 인용·코드 내부는 변경하지 않는다. 새 텍스트나 내용을 삽입하지 않고 확정된 경계의 공백만 바꾼다.

기존 범위별 180문장/40문단 상한은 늘리지 않았다. 최대 문서 길이·제목 수도 제한한다. 운영 비동기 경로는 제목 구간 및 제한된 비교 묶음마다 실행권을 반환하고 기존 취소 신호를 따른다. 동기 호환 함수와 비동기 함수의 결과 동일성을 검사했다. 제목이 없거나 모호한 경우 무리하게 대응시키지 않는다.

## 실제 저장 입력 재생

원문 20,669자·294문장, 결과 21,049자·322문장을 사용했다. 변경 전후 모두 기존 최종 레이아웃 경로로 기본/고급을 각각 재생했다. 변경 전도 전체 구조·가독성 pass였으나 지적한 논점 전환은 붙어 있었다. 변경 후 해당 경계가 분리됐고 기본/고급 모두 최종 구조·가독성·수렴 검사를 통과했다. 경계 복원 단계에서 8개 경계를 정리했다. 결과의 비공백 문자열은 완전히 동일하다. 사용자 원문·결과는 저장소에 포함하지 않았다.

유료 모델 재생성이나 운영 요청 검증은 아니다. 이 변경은 저장된 결과의 레이아웃 파이프라인을 재생해 검증했다. 실서비스 화면과 당시 엔진 버전까지 확인한 것으로 확대하지 않는다.

## 회귀

문서 전체 180문장 초과, 단일 개행, 중복/불일치 제목, 인용·짧은 물리적 줄바꿈, 이미 정상인 빈 줄, 반복 적용 고정점, 취소 및 동기/비동기 일치를 합성 자료로 검사한다. 최종 코드 전체 회귀 2,776/2,776 통과(228.925초), FLOOR 88/88 및 운영 import 검사 통과. 이 시간은 테스트 실행 시간이며 운영 처리 성능을 뜻하지 않는다.
