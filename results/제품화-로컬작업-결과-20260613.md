## 완료

### 0-A. transform 소유자 검증

- `GET /transform/:id`
- `POST /transform/:id/cancel`
- `POST /transform/:id/approve`

위 3개 라우트에 Firebase ID Token 검증과 `job.uid` 소유자 검증을 추가했다.

프론트 `evasion-flow.js`는 transform polling/approve/cancel 요청에 `Authorization: Bearer <idToken>`을 붙이는 구조다.

로컬 `DEV_NO_AUTH=1` + Firebase 미설정 상황에서는 기존 개발 흐름을 깨지 않도록 dev job만 우회한다.
